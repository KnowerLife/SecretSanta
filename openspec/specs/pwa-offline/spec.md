# pwa-offline Specification

## Purpose

Определяет поведение PWA: установку приложения, доступность оболочки без сети и отложенную отправку сообщений после восстановления соединения.

## Requirements

### Requirement: Устанавливаемое PWA

Система MUST предоставлять манифест с режимом `standalone`, иконками и путём запуска, позволяющим установить приложение на устройство.

#### Scenario: Установка приложения

- **WHEN** пользователь открывает сайт в поддерживаемом браузере и выбирает «Установить»
- **THEN** приложение добавляется на рабочий стол и запускается без адресной строки браузера

### Requirement: Офлайн-оболочка

Система MUST кешировать оболочку приложения и возвращать запасную страницу при отсутствии сети.

#### Scenario: Открытие без сети

- **WHEN** пользователь открывает уже посещённое приложение без подключения к сети
- **THEN** отображается кешированная оболочка с понятным баннером о недоступности сервера

### Requirement: Очередь сообщений

Система MUST сохранять сообщения, отправленные без сети, и отправлять их автоматически после восстановления соединения.

#### Scenario: Отправка в офлайне

- **WHEN** пользователь отправляет сообщение без сети
- **THEN** сообщение попадает в локальную очередь, отображается как ожидающее и не теряется при перезагрузке

#### Scenario: Восстановление соединения

- **WHEN** браузер получает событие `online` или сигнал Background Sync
- **THEN** система сбрасывает очередь, отправляет сообщения и обновляет историю чата

#### Scenario: Превышение попыток

- **WHEN** сообщение не удаётся отправить после 10 попыток
- **THEN** система прекращает автоматические повторы и сохраняет сообщение в очереди для ручной обработки

### Requirement: Подсказки установки

Система MUST показывать понятные подсказки установки PWA в шапке, футере и для iOS, а также обновлять их при смене языка.

#### Scenario: Поддерживаемый браузер

- **WHEN** браузер вызывает `beforeinstallprompt`
- **THEN** система показывает кнопку установки и текстовую подсказку, доступную на RU и EN

#### Scenario: iOS

- **WHEN** пользователь открывает приложение в Safari на iOS без события установки
- **THEN** система показывает пошаговую подсказку через «Поделиться» → «На главный экран»

#### Scenario: После установки

- **WHEN** приложение установлено или уже запущено автономно
- **THEN** система скрывает подсказки и показывает состояние «установлено»

### Requirement: Офлайн-игра целиком

Система MUST сохранять работоспособность создания комнаты, жеребьёвки, вишлистов, чата и журнала при недоступном API, а не только офлайн-оболочку и очередь сообщений.

#### Scenario: Полный офлайн-сценарий

- **WHEN** сеть недоступна и пользователь создаёт комнату, добавляет пожелания, проводит жеребьёвку и пишет в чат
- **THEN** все действия выполняются локально и остаются доступными после перезагрузки страницы

#### Scenario: Восстановление сети

- **WHEN** соединение восстанавливается
- **THEN** система предлагает явный выбор между отправкой локальных изменений и их сохранением без перезаписи серверных данных

#### Scenario: Язык и подсказки офлайна

- **WHEN** пользователь меняет язык в офлайн-режиме
- **THEN** текст подсказок установки и состояния сети обновляется без перезагрузки страницы
