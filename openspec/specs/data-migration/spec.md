# data-migration Specification

## Purpose

Определяет перенос существующих игр из хранилища v68 в хранилище v69: какие данные сохраняются, как проверяется целостность и как обеспечивается повторяемость переноса без изменения исходной базы.

## Requirements

### Requirement: Полнота переноса данных

Система MUST переносить комнаты, участников, сессии, токены, исключения, вишлисты, профили, забеги жеребьёвки, назначения, сообщения и журнал событий из базы v68 в базу v69.

#### Scenario: Перенос комнаты

- **WHEN** запускается миграция с существующей базой v68
- **THEN** каждая комната появляется в v69 с тем же кодом, названием, датой, бюджетом и организатором

#### Scenario: Сохранение доступов

- **WHEN** участник переносится вместе с сессией
- **THEN** его member-токен и invite-токен продолжают работать в v69 без повторного приглашения

### Requirement: Приватность при переносе

Система MUST сохранять приватность назначений: полный список пар не должен становиться доступным через перенесённые данные или отчёты миграции.

#### Scenario: Перенос жеребьёвки

- **WHEN** переносится забег жеребьёвки
- **THEN** назначения сохраняются в виде пар, доступных только их участникам, а отчёт миграции содержит лишь агрегированные счётчики

### Requirement: Идемпотентность и проверка целостности

Система MUST позволять повторно запускать миграцию без дублирования данных и MUST проверять совпадение счётчиков после переноса.

#### Scenario: Повторный запуск

- **WHEN** миграция запускается второй раз на том же наборе файлов
- **THEN** данные не дублируются, а результат совпадает с первым запуском

#### Scenario: Расхождение счётчиков

- **WHEN** количество перенесённых записей отличается от ожидаемого
- **THEN** миграция прерывается с ошибкой, а частично записанные данные могут быть откачены

### Requirement: Неизменность источника

Система MUST NOT изменять базу v68 при переносе.

#### Scenario: Проверка исходного файла

- **WHEN** миграция завершается
- **THEN** контрольная сумма исходной базы v68 совпадает со значением до запуска
