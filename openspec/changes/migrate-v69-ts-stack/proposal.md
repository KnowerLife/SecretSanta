# Proposal

## Why

Рабочая версия v68 построена на ES-модулях без типов и на Python-бэкенде со стандартной библиотекой: масштабирование функциональности, SSR, единая система тем и выпуск релизов требуют всё больше ручных проверок. Параллельная миграция позволяет сохранить работающую v68 и перевести продукт на типизированный стек React/Vite/Hono без big-bang-риска.

## What Changes

- Добавить монорепозиторий npm workspaces: `apps/web` (TanStack Start, React, Vite 8 на Rolldown, Mantine 9), `apps/api` (Hono на Node.js), `packages/shared` (типы, RU/EN-словарь, алгоритмы), `packages/art` (SVG-сцены).
- Переписать frontend на TypeScript с FSD-слоями `app`, `pages`, `widgets`, `features`, `entities`, `shared`; маршрутизация TanStack Router, серверные данные TanStack Query, SSR через TanStack Start.
- Переписать backend на TypeScript/Hono с SQLite через `node:sqlite`, сохранив публичные контракты `/api/*` и правило «participant видит только своё назначение».
- Заменить 36 растровых JPG-иллюстраций SVG-сценами с тремя палитрами и детерминированным рендером.
- Внедрить OpenSpec как источник правды для требований: базовые спеки и этот change с proposal/specs/design/tasks.
- Внедрить Gitflow: ветки `main`, `develop`, `feature/*`, `release/*`, `hotfix/*`, семантические теги `vX.Y.Z` и CHANGELOG.
- **BREAKING**: новая маршрутизация `/room/$code` вместо hash-навигации `#dashboard`; старый UI v68 остаётся доступен до релиза v69 как отдельная точка входа.
- Сохранить существующие браузерные проверки и CI для v68 до достижения паритета функций.

## Capabilities

### New Capabilities

- `room-gameplay`: создание комнат, вход по коду/токену, серверная жеребьёвка, исключения, вишлисты, статусы подарков, чат и журнал активности.
- `server-rendering`: серверный рендеринг страниц, гидратация, метаданные и линкование стилей до загрузки JS.
- `localized-themes`: RU/EN-локализация, три темы, контраст и доступные элементы управления.
- `svg-scenes`: векторные иллюстрации с детерминированным составом и тематическими палитрами.
- `pwa-offline`: установка PWA, офлайн-кэш и отложенная отправка сообщений.

### Modified Capabilities

- Нет: в репозитории ещё не было зафиксированных специй.

## Impact

Затронуты корневой `package.json` и lockfile, CI, каталоги `apps/`, `packages/`, `openspec/`, `docs/`, а также README. Текущие `index.html`, `app.js`, `src/`, `styles.css`, `sw.js`, `backend/` и `scripts/` остаются нетронутыми и продолжают работать до релиза v69. Новый API использует отдельный SQLite-файл, поэтому миграция данных между бэкендами выполняется явно, а не автоматически.
