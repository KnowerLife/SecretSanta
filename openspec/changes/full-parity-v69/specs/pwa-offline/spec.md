# Spec Delta

## ADDED Requirements

### Requirement: Подсказки установки

Система MUST показывать понятные подсказки установки PWA в шапке, футере и для iOS, а также обновлять их при смене языка.

#### Scenario: Поддерживаемый браузер

- **WHEN** браузер вызывает `beforeinstallprompt`
- **THEN** система показывает кнопку установки и текстовую подсказку, доступную на RU и EN

#### Scenario: iOS

- **WHEN** пользователь открывает приложение в Safari на iOS без события установки
- **THEN** система показывает пошаговую подсказку через «Поделиться» → «На главный экран»

#### Scenario: После установки

- **WHEN** приложение установлено или уже запущено автономно
- **THEN** система скрывает подсказки и показывает состояние «установлено»

### Requirement: Офлайн-игра целиком

Система MUST сохранять работоспособность создания комнаты, жеребьёвки, вишлистов, чата и журнала при недоступном API, а не только офлайн-оболочку и очередь сообщений.

#### Scenario: Полный офлайн-сценарий

- **WHEN** сеть недоступна и пользователь создаёт комнату, добавляет пожелания, проводит жеребьёвку и пишет в чат
- **THEN** все действия выполняются локально и остаются доступными после перезагрузки страницы

#### Scenario: Восстановление сети

- **WHEN** соединение восстанавливается
- **THEN** система предлагает явный выбор между отправкой локальных изменений и их сохранением без перезаписи серверных данных

#### Scenario: Язык и подсказки офлайна

- **WHEN** пользователь меняет язык в офлайн-режиме
- **THEN** текст подсказок установки и состояния сети обновляется без перезагрузки страницы
