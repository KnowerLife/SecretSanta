### SSR и API

- `GET /` → 200, HTML содержит `lang="ru"`, `data-theme="winter"`, подключение `mantineCoreStyles` первым и сцены `hero-winter`.
- `GET /room/<code>` с cookie `ss_token` → 200, имя и код комнаты отрендерены на сервере.
- Две комнаты с разными токенами: SSR выбирает cookie `ss_token_<CODE>` и неподменно рендерит нужную комнату (A≠B).
- `GET /api/health` → `{"ok":true,"version":"0.3-v69","stack":"hono-node"}`.
- `GET /api/rooms/<code>/assignment` возвращает только назначение текущего участника (тест изолирован).

### Браузерные сценарии (Playwright, 0 ошибок консоли)

- Переключение темы: `winter → midnight`; переключение локали: `ru → en → ru`; атрибуты `data-theme` и `lang` обновляются.
- Быстрая жеребьёвка: 4 введённых имени → 4 строки результата; доступны CSV, печать и персональная ссылка.
- Создание комнаты → редирект в `/room/<code>`; дашборд показывает код, имя, вкладки и статусы; после F5 данные приходят с сервера.
- Офлайн-очередь: при `offline` сообщение попадает в `localStorage`, после `online` отправляется ровно один раз и удаляется из очереди.

### Доступность

- Lighthouse accessibility (6 сочетаний: 3 темы × 2 локали): **1.00** в каждом прогоне, `color-contrast` — 0 проблем.
- Контраст исправлен через темы `--santa-on-primary`, `--santa-on-accent`, `--santa-primary-text`; Mantine-палитра приведена к CSS-переменным.

## Известные отличия до релиза

- База v69 (`apps/api/data/app.db`) отделена от `backend/data/app.db`; миграция данных v68 не выполнена.
- SSE-шина в памяти: горизонтальное масштабирование потребует Redis.
- `backend/prod_stack/` остаётся каркасом: production-деплой v69 ещё не настроен.
- Старые браузерные проверки проверяют v68 на `127.0.0.1:8080`; новый стек работает на `localhost:3000` + API `8787`.
- `release/v69.0.0` и тег `v69.0.0` созданы после явного разрешения владельца; production-деплой v69 ещё не настроен.
